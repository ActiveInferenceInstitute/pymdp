# `pymdp.algos`

For a one-frame VMP window, absent or empty `past_actions` is valid and the
supplied initial prior remains informative. It is not replaced by a uniform
prior. Longer-window learning sufficient-statistic accounting remains the
separate P2 scientific-policy decision.
